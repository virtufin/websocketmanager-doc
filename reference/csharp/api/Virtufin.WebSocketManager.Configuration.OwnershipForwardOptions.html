Tuning for the optional owner-replica forwarding path. When MissesPerMinuteThreshold is 0 (default), the WSM never forwards cross-instance RPCs and the caller receives StatusCode.FailedPrecondition on every miss. Set the threshold to a non-zero value to enable forwarding only after the running 5-minute miss rate exceeds it.

Remarks

The forward uses Dapr service invocation (DaprClient.InvokeMethodAsync) against the owning replica's app id (websocketmanager) so callers do not need cluster topology knowledge.
