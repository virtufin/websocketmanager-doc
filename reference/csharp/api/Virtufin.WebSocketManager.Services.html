ApiLifecyclePublisher

Publishes connection lifecycle events to the virtufin-api's system-events topic. Events are CloudEvents v1.0 envelopes with the WSM's URN as the source. The publisher is best-effort: failures are logged but never propagated, so an unreachable API does not break the WSM's local connection state machine.

TopicValidator

Validates Dapr pubsub topic names against the patterns in the Pub/Sub Topics spec §Topic Patterns.

The WebSocketManager publishes per-frame user data to caller-supplied topics (the topic passed to StartPublishRequest.topic). Per Cross-cutting spec, services that publish directly to Dapr MUST validate the topic name inline against these patterns. This class is the chokepoint that enforces the rule.

Accepted patterns:

  1. <service>.<category> — Tier 0 / infrastructure e.g. websocketmanager.lifecycle, workmanager.infra.worker
  2. act.exchange.<venue>.<entity>.<event>[.<id>] — market data (real, no selector segment)
  3. hyp.<selector>.exchange.<venue>.<entity>.<event>[.<id>] — market data (hypothetical, with selector)
  4. sc.<scenarioId>.<domain>.<entity>.<event>[.<id>] — scenario-scoped events
  5. command.<service> — command topics (worker input)
  6. response.<service> — response topics (worker output)

Rejected (intentionally):

  • act.<selector>.exchange.* — act topics MUST NOT carry a selector
  • hyp.exchange.* — hyp topics MUST carry a selector
