Remarks

Each WSM replica must advertise a routable gRPC endpoint so peer replicas can dial it directly. In a Kubernetes cluster, set WSM_GRPC_HOST to the pod IP (or service DNS name) and WSM_GRPC_PORT to the gRPC service port. In deploy-local (where everything is on localhost), the defaults are localhost + the gRPC port chosen at startup.
