gRPC service for the WebSocketManager. RPCs that target a specific connection (Disconnect, StartPublish, StopPublish, Send, SendRaw) are routed to the owning replica via Dapr virtual actors: an ActorProxy.Create<IWebSocketConnectionActor>(id) routes the call through Dapr's placement service.
