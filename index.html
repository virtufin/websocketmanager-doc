    Virtufin WebSocket Manager - Documentation

    Welcome to the Virtufin WebSocket Manager documentation. This service provides centralized WebSocket connection management with gRPC API support and Dapr integration for distributed state and pub/sub messaging.

    Documentation Index

    Architecture Overview

    System architecture, component relationships, and data flow. Learn how all components fit together to provide distributed WebSocket management.

    Services

    Detailed documentation for all service classes: - IWebSocketService / WebSocketService - Core WebSocket management - IWebSocketConnectionStore / DistributedWebSocketConnectionStore - Connection storage with Dapr persistence - IDaprConnectionRepository / DaprConnectionRepository - Dapr state store operations - IWebSocketClientWrapper / WebSocketClientWrapper - Low-level WebSocket operations - IDaprPublisher / DaprPublisher - Pub/sub message publishing - IInstanceIdProvider / DefaultInstanceIdProvider - Instance identification

    Configuration

    Configuration constants and options: - PortConstants - Port configuration values - DaprConstants - Dapr component names and keys - WebSocketOptions - WebSocket behavior options

    Quick Start

    Starting the Service

    # Run with default ports (HTTP: 5001, gRPC: 5002)
dotnet run

# Specify custom ports
dotnet run -- --http-port 8080 --grpc-port 9090

# Specify Dapr ports
dotnet run -- --dapr-http-port 3500 --dapr-grpc-port 50001

    Connecting to a WebSocket

    Using gRPC:

    var client = new WebSocketManager.WebSocketManagerClient(channel);
var response = await client.ConnectAsync(new ConnectRequest
{
    Url = "wss://example.com/socket",
    AutoReconnect = true
});
Console.WriteLine($"Connected with ID: {response.Id}");

    Publishing Messages to Dapr

    // Start publishing to a topic
await client.StartPublishAsync(new StartPublishRequest
{
    Id = connectionId,
    Topic = "websocket-events"
});
